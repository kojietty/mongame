# アビリティ

モンスターは通常特性と歪み特性の2種類を持ちます。歪み特性は強力ですが明確な代償があります。

---

## 通常特性

通常特性は1〜2個持つことができます。

### 発動タイミング

| トリガー | 発動条件 |
|---------|---------|
| `start` | 戦闘開始時（1回のみ） |
| `low50` | HPが50%以下のとき |
| `onHit` | 攻撃するたび（毎ターン攻撃時に） |
| `everyTurn` | 毎ターン（攻撃に関わらず） |
| `slower` | 相手より遅いとき |

### 効果の種類

| 種類 | 効果 | 値の候補 |
|------|------|---------|
| `statUp` | 指定能力+○% | 10%, 15%, 20%, 25%, 30% |
| `typeDmgUp` | 指定属性の与ダメージ+○% | 15%, 20%, 30%, 40% |
| `typeResist` | 指定属性の被ダメージ-○% | 15%, 20%, 30% |
| `heal` | 最大HPの○%回復 | 5%, 8%, 10%, 12% |
| `crit` | クリティカル率+○% | 10%, 15%, 20%, 30% |

### statUp の注意点

`statUp` のうち、攻撃(1)・特攻(3)に適用されるものは**半分の効果**で適用されます。

```
damage bonus = 1 + (pct / 100 × 0.5)
```

## 歪み特性（諸刃の剣）

歪み特性は確率で個体に最初から付与され、育成中の「歪み」が閾値を超えると後天的にも発現します。

### 初期歪み特性の確率（レアリティ依存）

| レアリティ | 歪み特性確率 |
|-----------|------------|
| N | 25% |
| R | 45% |
| SR | 70% |
| UR | 100% |

### 後天特性の発現

歪み値が **80** と **180** の2つの閾値に達するたびに、後天特性が1つ発現します。

- 発現する特性は「最も鍛えた能力」に紐づく
- 最大で**2つ**の後天特性を獲得可能

---

### 歪み特性の種類

#### 1. 属性矛盾（`offType`）— 出現率 40%

攻撃属性を別の属性に変更し、**超火力**を発揮するが、被ダメージも激増する。

| パラメータ | 値 |
|-----------|-----|
| 属性変更先 | ランダム（自属性以外） |
| 与ダメージ増加 | +40% 〜 +200% |
| 被ダメージ増加 | +5% 〜 +300%（= 増加量の1/8、最大300%） |

```
攻撃時: pdxMult *= (1 + pct / 100)
防御時: pdxMult *= (1 + selfHurt / 100)
```

**戦略的価値**: 属性相性を無視して相手の弱点に攻撃できるが、自分の被弾が大幅に増える。先手を取れる場合に強い。

---

#### 2. 条件覚醒（`condMult`）— 出現率 26%

特定条件で**巨大な倍率**を得るが、条件を満たさない間は能力が半減する。

| パラメータ | 値 |
|-----------|-----|
| 条件 | HP1/4以下 / 偶数ターン / 奇数ターン / HP50%以上 |
| 条件充足時倍率 | ×3 / ×5 / ×7 / ×10 |
| 条件未充足時倍率 | **×0.5**（半減） |

```
effStat = baseStat × permMult × (条件充足 ? mult : 0.5)
```

**戦略的価値**: 偶数ターンのみ×10など、極端なスイングが可能。しかしターン管理が必要。

---

#### 3. 等価交換（`exchange`）— 出現率 20%

1つの能力を極振りし、もう1つの能力を崩壊させる。

| パラメータ | 値 |
|-----------|-----|
| 上昇能力 | +300% 〜 +1800% |
| 下降能力 | -90% / -95% / -99% |

```
permMult[up] *= (1 + upPct / 100)    // 例: ×4 〜 ×19
permMult[down] *= (1 - downPct / 100) // 例: ×0.01 〜 ×0.1
```

**戦略的価値**: 攻撃だけを極限まで伸ばして一撃必殺を狙う。あるいはHPを犠牲にして攻撃に振り切る。

---

#### 4. 無意味特化（`useless`）— 出現率 14%

特定の条件に合致する相手に対して猛烈な火力だが、**他の全相手には-40%**。

| 条件 | 詳細 |
|------|------|
| `sameType` | 自分と同じタイプの相手 |
| `lowerHP` | 最大HPが自分より低い相手 |
| `nameRa` | 名前に「ラ」を含む相手 |

```
条件充足時: pdxMult *= (1 + pct / 100)  // +300% 〜 +2000%
条件不充足時: pdxMult *= 0.6             // -40%
```

**戦略的価値**: 特定の相手に特化するが、それ以外では著しく弱体化。運要素が大きい。

---

## アビリティ名の生成

各アビリティはランダムな名前が付けられます。

```
「」 + (歪んだ) + [灼熱/逆流/天罰/...] + [の構え/の呪い/の加護/...]
```

歪み特性には先頭に「歪んだ」が付きます。
