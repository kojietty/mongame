# モンスター生成

個体コードをseedとして**シード付き乱数**を用い、見た目・ステータス・性格・アビリティをすべて決定論的に生成します。

---

## 個体コードの構造

```
playerId | word | nonce
```

- `playerId`: プレイヤーID（他人と被らない保証）
- `word`: 任意の文字列
- `nonce`: ランダム文字列（`Math.random().toString(36).slice(2, 8)`）

→ 個体コード自体がすべての生成の**シード**となる。

---

## 生成されるもの

個体コードから以下のすべてが導出されます。

| 項目 | 生成方式 | 詳細 |
|------|---------|------|
| 名前 | 3文字組み合わせ | 先頭16種 × 中間12種 × 末尾12種 |
| レアリティ | シード付き乱数 | N/R/SR/URの4段階 |
| タイプ | 1〜2種 | 30%で2種類持つ |
| 基礎ステータス | 予算ベース配分 | HP・攻撃・防御・特攻・特防・素早さ |
| 性格 | 7種から選択 | 1能力+10%、1能力-10% |
| 通常特性 | 1〜2個 | 戦闘中のボーナス効果 |
| 歪み特性 | 0〜1個 | 諸刃の剣（確率で獲得） |
| スプライト | 48x48セルオートマトン | 完全に個体コードから決定 |

---

## レアリティ

| レアリティ | 星 | 排出率 | ステータス予算ボーナス | 歪み特性確率 |
|-----------|-----|--------|---------------------|------------|
| N | ★ | 55% | +0 | 25% |
| R | ★★ | 30% | +45 | 45% |
| SR | ★★★ | 12% | +95 | 70% |
| UR | ★★★★ | 3% | +160 | 100% |

---

## ステータス生成アルゴリズム

```
1. 基礎予算 = 240 + レアリティボーナス + randint(-15, 15)
   N: 225〜255 / R: 270〜300 / SR: 320〜350 / UR: 385〜415

2. 各能力にランダム重みを割り当て、予算を配分
   各値 = max(10, round(予算 × 重み / 重み合計))

3. 性格適用
   +10%される能力、-10%される能力が各1つ

4. 最終基礎値
```

---

## スプライト生成

48x48ピクセルのスプライトは以下のステップで生成されます。

1. **半分のグリッド（24x48）に乱数でブロブを配置**
2. **セルオートマトンを2〜4回実行**（密度5以上で生存、2以下で消滅）
3. **左右対称に展開**（24x48 → 48x48）
4. **最大連結成分のみ保持**（孤立ピクセル除去）
5. **面積が不足している場合は楕円フォールバック**
6. **外周に棘・角を追加**（密度が高いほど多い）
7. **深度ベースのシェーディング**（4色ゾーン + パレット）
8. **顔の配置**（目2つ + 口）

→ 同じ個体コードなら**必ず同じスプライト**が生成される。
