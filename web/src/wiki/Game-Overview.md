# ゲーム概要

**MONSTER LAB** は、48x48ドットの唯一無二モンスターを生成し、育成してPvP/PvEで対戦するオンラインRPGです。

---

## 基本ループ

```
ガチャで召喚 → 育成で強化 → 対戦で報酬を獲得 → さらに召喚・育成
```

1. **召喚（ガチャ）**: チケットを使用してモンスターを召喚。個体コードから見た目・ステータス・性格・アビリティがすべて決定論的に決まる
2. **育成**: 育成メニューを選択して1日日経過。経験値・努力値・歪みが変動し、Lv50まで成長
3. **対戦**: PvP（マッチメイキング）またはPvE（チャレンジモード）に挑戦

---

## 決定論エンジン

このゲーム最大の特徴は**完全な決定論**です。

- 同じ「個体コード」を与えば、**必ず同じモンスター**が生成される
- 戦闘も入力（両者のコード＋育成状態）が同じなら**必ず同じ結果**になる
- サーバーが計算を実行し、クライアントはリプレイを再生するだけ → **チート不能**
- 画像もステータスもDBに保存せず、個体コードから再計算で復元できる

---

## プレイヤーの目標

| 目標 | 内容 |
|------|------|
| 図鑑コンプ | 多くのモンスターを召喚・捕獲し図鑑を埋める |
| 最強モンスター育成 | 才能Sの個体を見つけ、努力値を極限まで振る |
| チャレンジ高スコア | できるだけ多くのステージを突破する |
| PvP勝利 | 他プレイヤーに勝利しレートを上げる |

---

## 用語集

| 用語 | 意味 |
|------|------|
| 個体コード | モンスターを一意に識別する文字列（`playerId|word|nonce`） |
| 基礎値 | 育成前の素のステータス |
| 努力値 | 育成で付与される追加ステータス |
| 才能グレード | 個体固有の育成効率（S/A/B/C/D） |
| 歪み | 歪み特性を発現させるための累積値 |
| 後天特性 | 歪みが閾値を超えた際に発現する歪み特性 |
