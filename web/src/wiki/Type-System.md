## 属性倍率計算

```javascript
function typeMult(atkIdx, defIdxs) {
  let m = 1;
  for (const d of defIdxs) {
    if (STRONG[atkIdx].includes(d)) m *= 2;    // 効果抜群: ×2
    else if (STRONG[d].includes(atkIdx)) m *= 0.5;  // 効果いまいち: ×0.5
  }
  return m;
}
```

### ルール

1. 防御側の**各属性**に対して判定
2. 攻撃が効果抜群 → **×2**
3. 防御が攻撃に対して有利 → **×0.5**
4. それ以外 → **×1**（変動なし）
5. 全ての防御属性の倍率を**掛け合わせる**

### 2重タイプ時の倍率

| 防御側組み合わせ | 倍率 |
|-----------------|------|
| 有利1 + 有利2 | ×0.25 |
| 有利1 + 中立 | ×0.5 |
| 中立 + 中立 | ×1 |
| 効果抜群1 + 中立 | ×2 |
| 効果抜群1 + 効果抜群2 | ×4 |

> **例**: 炎(攻) vs 草+氷(防) → 2 × 2 = **4倍**
> **例**: 炎(攻) vs 水(防) → 水が炎に対して有利 → **0.5倍**
