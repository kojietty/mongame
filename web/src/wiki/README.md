## 計算式早見表

| 項目 | 式 |
|------|-----|
| HP | `round(baseHP × 永続倍率 × 3.2 + 40)` |
| ステータス | `round(baseStat × (1 + Lv × 0.03)) + effort` |
| 努力値上昇 | `round(基礎値 × 才能グレード × 好調倍率)` |
| 経験値必要量 | `20 + Lv × 10` |
| ダメージ | `max(1, round((6 + eATK² / (eATK + eDEF)) × 属性相性 × ダメボス × 耐性 × 歪み倍率 × クリ倍率 × バラつき))` |
| クリ率 | `min(0.6, 0.05 + アビリティ補正)` |
| 敵ステータス倍率 | `0.6 + 0.15 × ステージ` |
| ガチャ排出率 | N:55% / R:30% / SR:12% / UR:3% |
| 捕獲率 | 10%（撃破時ごとに独立判定） |
